# Білім порталы

Единая платформа сайтов школ и детских садов области. Около 600 организаций получают готовый сайт с обязательными разделами. Платформа работает на сервере области, для организаций бесплатно. Управление и отделы образования видят заполненность сайтов, сроки ответов на обращения и активность в одном окне.

Стек: **Node.js 20+ · Express · PostgreSQL · React 18 · Vite · TypeScript**.

---

## Быстрый старт (без установки PostgreSQL)

```bash
npm install
cd apps/api && SEED_DEMO=true npm run dev     # API на :4000, встроенный PostgreSQL (PGlite) в ./data
cd apps/web && npm run dev                    # кабинет на http://localhost:5173
```

Откройте http://localhost:5173 → **Войти** → вкладка **«Демо-вход»** → выберите любую из 13 учётных записей.

Демо-данные:
- 10 районов и городов области Жетісу;
- 600 условных организаций;
- школа №1 (г. Талдыкорган) и детский сад «Нұрай» №1 с классами, детьми, родителями, заданиями, перепиской и поручениями.

> Демо-вход (`AUTH_DEV_LOGIN=true`) — только для разработки и показа. В рабочей среде отключите его.

## Роли и что они видят

Все ограничения проверяются **на сервере** (`apps/api/src/lib/scope.ts`), а не только в интерфейсе.

| Роль | Зона данных | Функции | Статистика |
|---|---|---|---|
| Оператор платформы | Вся платформа | Сообщение о техработах, журнал, выдача доступа администраторам области | Нагрузка, учётные записи по ролям, объём данных |
| Администратор области | Все организации | Мониторинг, замечания, требования к сайтам, срок ответа на обращения, объявления на все сайты, лента новостей, выгрузка CSV, назначение администраторов районов | Заполненность по районам, активность, обращения, замечания |
| Наблюдатель (акимат) | Все организации, только чтение | Мониторинг, выгрузка CSV | То же, что у области |
| Администратор района | Организации своего района | Замечания и их приёмка, назначение руководителей, контроль обращений, объявления и лента для района | Всё то же по району |
| Руководитель | Своя организация | Сайт, публикации, документы, ответы на обращения, классы, сотрудники, поручения персоналу, внутренние объявления | Публикации, документы, обращения, охват семей, поручения |
| Редактор | Сайт своей организации | Проверка и публикация материалов, разделы, документы с файлами, исправление замечаний, авторы | Публикации, документы, авторы |
| Автор | Свои материалы | Черновики → на проверку редактору | Статусы своих материалов |
| Педагог / воспитатель | Только свой класс или группа | Список детей, доступ родителям и ученикам по телефону, задания и объявления, переписка с родителями | Охват родителей, выполнение заданий, скорость ответа родителям |
| Сотрудник (медсестра, бухгалтер…) | Свои поручения | Выполнение поручений с отчётом, объявления для персонала, коллеги | Поручения: в работе, просрочено, выполнено |
| Родитель | Только свои дети | Карточка каждого ребёнка, объявления, задания, переписка с педагогом, вопрос руководителю | Выполнение заданий, пропущенные сроки, новые сообщения |
| Ученик | Свой класс | Задания с отметкой «сделано», объявления, новости школы | Выполнение по предметам, ближайшие сроки |
| Посетитель | Публичные данные | Каталог, сайт организации на KZ/RU/EN, обращение к руководителю, проверка ответа по номеру, новости образования | — |

**Цепочка выдачи доступа:** оператор → область → район → руководитель → редактор, педагоги и персонал → педагог → родители и ученики.

## Вход

- **Сотрудники — по ЭЦП НУЦ РК.**
  1. Браузер подписывает одноразовый код в NCALayer (ключ AUTH).
  2. Сервер проверяет подпись и отзыв сертификата в [NCANode](https://github.com/ncanode/ncanode).
  3. Пользователь находится по ИИН из сертификата.

  Поэтому при выдаче доступа сотруднику обязательно указывается его ИИН. Настройка — переменная `NCANODE_URL`.
- **Родители и ученики — по SMS-коду** на номер, который указал педагог. Провайдер задаётся в `SMS_PROVIDER`: `mobizon` для Mobizon.kz или `console`, который печатает код в лог при разработке. Для провайдера есть ограничение частоты запросов и лимит попыток.
- Сессия хранится в httpOnly-cookie (JWT, 7 дней). Изменяющие запросы с чужих доменов отклоняются.

> Сверьте формат ответа `/cms/verify` с версией NCANode, которую вы развернёте. ИИН извлекается функцией `findIin` в `apps/api/src/auth/ecp.ts`.

## Развёртывание на сервере области

```bash
cp .env.example .env        # заполните JWT_SECRET, домен, NCANODE_URL, MOBIZON_API_KEY
docker compose up -d --build
```

- В `docker-compose.yml` три сервиса: PostgreSQL 16, приложение и NCANode. Приложение само применяет миграции при старте и раздаёт собранный фронтенд.
- Перед сервером поставьте nginx с HTTPS и wildcard-сертификатом `*.bilim-zhetisu.kz`, если нужны поддомены организаций.
- Загруженные документы хранятся в томе `uploads`. Для S3 или MinIO замените `apps/api/src/lib/storage.ts`.
- Резервное копирование: `pg_dump` базы и копия тома `uploads` раз в сутки.

**Загрузка реального справочника организаций** (выгрузка из НОБД, CSV через `;`):

```bash
npm run import:orgs -w apps/api -- ./orgs.csv
# заголовки: id;district_id;kind;name;slug;bin;director;phone;address;lang;size
```

Районы задаются в таблице `districts`. Для другой области замените список в `apps/api/src/seed.ts` или вставьте районы SQL-запросом.

## Структура

```
apps/api/
  migrations/001_init.sql    схема БД (21 таблица)
  src/auth/                  сессии, ЭЦП (NCANode), SMS-коды
  src/lib/scope.ts           зоны видимости — кто какие данные видит
  src/routes/
    public.ts                каталог, сайт организации, обращения, файлы
    site.ts                  сведения, разделы, публикации, документы
    control.ts               замечания, обращения, объявления, пользователи, требования, журнал
    school.ts                классы, дети, доступ семей, задания, переписка, поручения
    feed.ts                  лента новостей
    stats.ts                 мониторинг и статистика по ролям
  test/api.test.ts           интеграционные тесты прав доступа
apps/web/src/
  pages/public/              каталог, сайт организации (KZ/RU/EN), новости
  pages/Login.tsx            ЭЦП, SMS, демо-вход
  pages/cabinet/             кабинеты: control, org, class, family, feed
```

## Проверка

```bash
npm test              # 11 интеграционных тестов API на PGlite: права каждой роли, сценарии от начала до конца
npm run typecheck     # TypeScript API и фронтенда
npm run build         # production-сборка
```

Тесты проверяют, например:
- район не может направить замечание в чужой район;
- родитель не видит переписку по чужому ребёнку;
- контакты заявителя видны только организации;
- педагог не публикует без редактора;
- лента соблюдает аудиторию.

## Что ещё нужно до промышленной эксплуатации

Следующие пункты осознанно не реализованы:

1. **Контент на трёх языках.** Сейчас на KZ/RU/EN переведены только названия разделов. Тексты организаций хранятся на одном языке. По Закону о языках нужна казахская версия контента: поля `*_kk` и переключатель в редакторе.
2. **Версия для слабовидящих** и полный аудит доступности.
3. **Интеграции:**
   - API НОБД для автоматической синхронизации справочника (сейчас есть импорт CSV);
   - вход через eGov Mobile;
   - электронный журнал для оценок.
4. **Уведомления** родителям и сотрудникам: push, e-mail, Telegram.
5. **Хранилище S3/MinIO, антивирусная проверка файлов, CDN** для публичных страниц.
6. **Аттестация ИС и защита персональных данных.**
   - Данные о детях хранятся только на сервере в РК.
   - Нужны согласия, политика конфиденциальности и регламент хранения.
   - Нужна проверка на соответствие требованиям ИБ, если платформа будет государственной ИС.
7. **Нагрузочное тестирование** на 600 сайтов и пиковые дни (приём в 1 класс, 1 сентября).
